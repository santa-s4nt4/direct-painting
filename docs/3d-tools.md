描画ツールを **Move / Line** に整理しました。Trail / Returnの新規作成とFilesのTrail計測リンクを外しています。保存済みの作品を消さずに読み込めるよう、旧レイヤーの互換再生は残しています。

## ビューの操作

- ピンチと−／＋は **50〜500%**。初期100%は4K中央の1920×1080です。50%では正面の4K全体を表示します。
- 2本指の距離でズーム、中点の移動でパン、指をひねると画面内で回転します。Draw with touchがOFFでも使えます。片指が残っている間は描画しません。
- キャンバス左下の回転ボックスを1本指でドラッグすると、左右の傾き（Y）と上下の傾き（X）が変わります。X/Yは±75°で、真横から見てペンの位置を逆算できなくなる姿勢を避けています。
- ボックスの面や **前 / 3D / 上 / 右** で姿勢を選べます。これらは現在の倍率・パンを保持します。上／右は描画できる60°の傾斜、3DはX=-25°、Y=-35°です。
- ボックスにフォーカスして矢印キーでX/Yを5°ずつ変更、Shift＋矢印でZ回転、Homeで正面へ戻せます。
- キャンバス下の倍率ボタンは **100%・中央・正面** にすべて戻します。正面での移動範囲は4K内に収め、回転した平面の輪郭は編集画面だけに表示します。
- 倍率・パン・X/Y/Zの角度は`/output`へ即時転送し、JSONとローカル保存に記録します。表示範囲は1920×1080基準で、配信解像度は表示領域に応じて1920×1080または1280×720になります。

Three.jsの[PerspectiveCamera](https://threejs.org/docs/pages/PerspectiveCamera.html)から、4KのPlaneGeometryを実際に透視投影しています。描画面には深度テスト・書き込みを有効にしました。ペンは同じ投影を逆変換して4Kの座標を求めます。CPU互換描画でも同じ投影を使います。

現在描く線・図形は3D空間内の平面に載ります。立体のブラシ、厚みや押し出しの編集は今回の範囲に含めていません。保存する筆跡の座標とGPUの顔料合成は、カメラから独立しています。

## 四角形のRing

DrawのShapeで **Rectangle · outline** を選ぶか、Rectangleで下部のRingをONにします。円のRingも同じボタンで切り替えられます。

- Width / Heightは筆圧のMin〜Max、Strokeは枠の太さです。
- Rotationの **0° / 45°** で切り替え、数値欄で任意の角度（−180〜180°）を指定できます。
- Layerでも形、寸法、Stroke、角度、0°／45°プリセットを後から変更できます。
- ブラー、混色、ライブ出力、JSON、Undo / Redoも枠の形を維持します。

## 2点の直線

1. 下部の **Line** を選びます。Widthは直線の太さです。
2. ペンで1点目をタップすると、その地点にRingが出ます。**接触した時刻**をループ上の開始時刻として記録します。
3. 2点目をタップすると2つ目のRingが出ます。最初の周回は端点の表示だけです。
4. 次に1点目の時刻へ到達したフレームで、2点を結ぶ直線全体が表示されます。以後も同じ時刻に再生し、Release fadeで消えます。

直線は2点を同時に結ぶもので、1点目から伸びるアニメーションにはしていません。端点のRingは細いペン入力でも見える64〜160px、枠は最大12pxの目印です。直線のWidthとは分けています。

- 1点目の取り消しは **Cancel first point**。完成した線は通常のレイヤーとして削除・Undoできます。
- 指でタップする場合はDraw with touchをONにします。マウスでも使えます。12 CSS px以上のドラッグやピンチは点として登録しません。
- Pauseでは次周回までの待機も止まります。シークは新しい位置から次の開始時刻へ待機を合わせ、ループ長・レイヤーのSTART変更も反映します。
- Restartは次周回として扱い、完成済みの線を開始時刻から再生可能にします。1点だけでは直線にしません。
- relayサーバーも待機を進め、iPadのタブを休止・終了しても出力側では直線へ切り替わります。遅れた初回スナップショットでRingへ戻らないようにしています。
- 未完成・待機中の線もJSONに保存できます。読み込み後は現在のループから次の開始時刻を待ちます。

## 保存形式と検証

プロジェクト形式はv1を継続し、カメラ設定を`settings.viewVersion: 3`へ移行します。旧10〜800%のファイルは50〜500%へ収め、筆跡を動かしません。カメラには`rotation`（Z）、`pitch`（X）、`yaw`（Y）を追加しています。

四角形の枠は`shape: "rect-ring"`。直線は`mode: "line"`、2点の`t: 0`、`duration: 0`、最初の接触時刻を`start`に保存します。`linePending`と`lineIncomplete`で初回表示を区別します。既存のMove・旧形式の図形データは保持します。
