# カメラモーション

キャンバス下のCameraで **normal / midi auto** を選びます。カメラは実際に3D空間を移動し、原点を向きます。描画平面は入力開始時の向きを保持するので、保存済みの図形も立体的に見回せます。編集中のストロークは同じ平面へ入力座標を逆投影し続けます。

## MIDI auto

1. MIDIタブの「入力デバイス（Mac）」で、MacにつないだMIDI入力を選びます。
2. Camera motionをONにします。下部のmidi autoも同時に選択されます。OFFにするとnormalへ戻ります。
3. 反応させたいノートを一度送ります。「反応するMIDIノート」に受信済み番号が追加されるので選択します。既定の24は未受信でも選べます。
4. 「変化させる項目」を座標のみ／拡大のみ／座標と拡大から選び、移動時間・イージング・拡大範囲を設定します。

Note Onを受けると、Macがランダムな方位・仰角と、必要に応じて倍率を決定します。方位は全周、仰角は±55°、中心からの距離は4500〜8500です。カメラはボックスの外側を移動し、原点を向き続けます。midi autoではパンを中央に置きます。

「座標のみ」は方位と仰角をランダムにし、距離と倍率は維持します。「拡大のみ」は倍率だけを変えます。「座標と拡大」は両方を変えます。拡大は初期値50〜200%の範囲から対数分布で選び、範囲は50〜500%で調整できます。移動時間は0.05〜16秒、初期値0.8秒です。Smooth／Ease in-out／Ease out／Linearからイージングを選べます。

選択したイージングで現在の状態から目的地へ移動し、到着後はその状態を保持します。次のNote Onでは、その時点のカメラ位置から新しい目標へ滑らかにつなぎます。元の基準位置への復帰はありません。Note Off、ベロシティ0、MIDIデバイスの切断は進行中の移動に影響しません。移動時間・イージング・拡大範囲は次のNote Onから適用します。座標／拡大の切替時は表示中の状態を保持し、次のNote Onから新しい軸だけを動かします。

全チャンネルを受け、選択したノートのNote Onだけを目標の更新に使います。ノート変更や入力デバイス切替は、すでに始まった移動を止めません。回転ボックスと正面ボタンはロックします。

**タイムラインの頭出しは引き続きノート24固定**です。カメラにも24を選ぶと、同じNote Onで頭出しとカメラ移動の両方が起きます。別のノートを選ぶと、カメラだけが反応します。カメラの移動はノートの長さに依存せず、タイムライン再生位置とも独立しています。

## Normalと旧recデータ

normalでは回転ボックスと2本指操作で向きを変えます。立方体の右にFrontとCamera切替を上下2段で置きます。ペンを離さず指で立方体を操作でき、指を離しても描画は続きます。カメラ操作でタイムラインを停止・頭出しすることはありません。**recは廃止**しました。録画開始／終了API、録画タイマー、録画した姿勢のループ再生も削除しています。

旧プロジェクトに`mode: 'rec'`があればnormalへ移行し、`track`を破棄します。絵・図形の平面・タイミング・MIDIノート・エフェクト設定は保持します。旧ADSR設定はAttackとDecayの合計を移動時間へ変換し、エンベロープ項目は保存しません。旧テイクの遅延パケットは無視し、手動カメラを動かしません。

## Camera Motion Blur

**Draw → Effects → Camera Motion Blur** は画面共通のエフェクトです。初期ON、Shutter 100%＝16.7ms、範囲0〜200%です。normalの手動操作、midi autoのいずれにも対応します。レイヤーごとのMotion blurは図形自身の動きを担当し、独立してON/OFFできます。静止しているLineも、カメラが動けばCamera Motion Blurでにじみます。

GPUは8〜16個のカメラ姿勢を同じレイヤーのシェーダーで評価し、図形自身の動きと合わせて色・透明度を平均してからAnalog合成します。画面全体の残像画像やレイヤーごとの追加描画先は保持しません。midi autoの露光姿勢は元の動きから計算し、手動操作では最大32個の短い姿勢履歴を使います。静止時は通常描画へ戻ります。

CPUフォールバックでも現行の円・矩形・3D Lineのカメラ露光を平均します。**旧Trail／Returnのビットマップ互換レイヤーに対するCamera Motion BlurはCPUでは未対応**です。通常の互換再生は継続します。

## 保存と同期

`settings.camera`へモード、対象ノート、動かす軸、移動時間、イージング、ランダム拡大範囲、Blur設定を保存します。初期値はnormal／ノート24／座標と拡大／0.8秒／Smooth／50〜200%／Camera Motion Blur ONです。

Macの`/api/camera`が設定とMIDIイベントを管理します。MIDIのランダムな目的地を端末ごとに作らず、発生時刻・始点・目標・移動時間・イージングを編集画面と`/output`へ同じSSEで配信します。古いプロジェクト同期は、新しいカメラ状態を上書きしません。遅れて接続した出力は全状態を取得して復帰します。

タイムラインは常に16秒、画面更新は60Hzです。カメラの設定を変更しても、再生位置や再生／停止状態は変えません。Pauseボタンは廃止し、通常は常時再生します。シーク後も再生を続け、リスタートと固定ノート24で頭出しできます。

描画のたびに回転ボックスとボックス枠のSVGを再生成していた処理を、カメラ姿勢が変わったときだけに限定しました。タイムラインの表示更新を描画より先に行い、次フレームの予約も描画前へ移しました。描画バックエンドで例外が起きても、以降のタイムライン更新が予約されます。これは、実機で60fpsが維持できることの保証ではありません。

## 確認範囲

- `npm test`：更新後の結果は下記の作業記録を参照。カメラ位置・中心向き、入力の逆投影、3種類の動作軸、拡大範囲、イージング、再トリガー、Note Off後の継続、旧rec／ADSR移行、保存、常時再生・シーク・MIDI頭出し・ペンと指の独立した同時操作を含みます。画面レイアウトを確認するテストではありません。
- `npm run test:midi -- artifacts/camera-midi-checks.json`：実CoreMIDI仮想入力で、固定24の頭出し、対象ノートの変更、Note Off／ベロシティ0／切断がカメラ移動を中断しないことを確認します。
- `npm run test:motion-gpu -- artifacts/camera-shader-checks.json /tmp/direct-object-blur.png artifacts/camera-motion-blur-comparison.png`：Apple M4 MaxのmacOSオフスクリーンGPUで本番GLSLを描画し17項目成功。カメラの周回・ロール・距離・図形の動きとの併用・境界・横向きの平面・透明度・保存平面を含みます。独立した各姿勢の描画を平均した参照との差は、カメラの8項目で最大RMS 0.0334／255、境界の一部で最大16／255でした。[結果](../artifacts/camera-shader-checks.json)を保存しています。
- `npm run test:gles -- artifacts/gles-layer-checks.json`：ANGLEの実OpenGL ES 3.0コンテキストで、修正前の精度不一致によるリンク失敗を再現し、修正後の通常／Analog両シェーダーのリンクと画素出力を確認しました。詳細は[描画不具合の記録](shader-precision.md)。
- `npm run build`：成功。既存のThree.jsチャンクサイズ警告があります。

ブラウザー操作機能に接続できなかったため、実ブラウザーのThree.js／WebGL2統合、画面レイアウト、iPad mini A17 Proの操作・描画速度は未確認です。`/benchmarks/motion.html`にカメラの画素比較・タイムラインから独立したMIDI姿勢・実カメラの向きの検証も用意していますが、今回は未実行です。CoreMIDIの確認は仮想入力であり、実オーディオインターフェースやTouchDesigner本体の実機確認を含みません。
